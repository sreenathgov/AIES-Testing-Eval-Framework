## GRI Analysis

**Resolved at GRI 1.**

India ITC-HS heading 8507.60 covers lithium-ion accumulators. India does not have a more specific 8-digit code for standalone Li-ion cells (unlike traction motors). Standard 8507.60.00 applies.
