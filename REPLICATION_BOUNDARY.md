# Replication Boundary

This repository is a bounded evidence harness for a legal extraction evaluation paper.

It is not a migration of the originating production architecture. It does not include the full graph, doctrine, memory state, company strategy material, complete staging folders, or any downstream product system.

The included source material is a cited EU/WCO/BTI subset. The included pre-HS inputs are limited to the 28 selected engineering components needed to run the HS case study. The included forensic evidence and reference baseline are comparison material, not runtime input.

The original source repository remains the system of record. This harness uses copy-only review-bundle generation and must not move, delete, or rewrite files in the source repository.
